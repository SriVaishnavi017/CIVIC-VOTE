CivicVote

Digital Election & Vote Auditing

Academic Microservice Demo

This frontend is intentionally separated from the backend services, which are implemented as independent Spring Boot modules for Auth, Election, Gateway, and Eureka discovery.

Auth

Register / login and receive JWT tokens.

Election

Create elections, candidates, and activate voting periods.

Gateway

Route all frontend requests via a single API entry point.

Eureka

Discover and register backend services dynamically.
